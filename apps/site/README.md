# anydot.app landing page

Static files served by nginx from `/var/www/anydot.app` on the anydot.app server. Deploy by copying `index.html`, `logo-mark.svg` and `images/` there; no build step. Download buttons link to `github.com/JinJieTan/anydot/releases/latest/download/AnyDot-<platform>.<ext>`: the Release workflow uploads version-free copies of each installer, so nothing here changes per release — just publish the draft Release.
