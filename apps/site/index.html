开源的 AI 桌面客户端。填入 Base URL 和 Key，就能用 GPT、Claude 对话、生图，在项目里写代码、跑命令；手机扫码或输入配对码，随时远程派任务。

在项目文件夹里让 AI 读写文件、跑命令，模型随时切换

一句话让它操作你的浏览器：打开网页、输入、读取结果

任意 Key

OpenAI、Anthropic 兼容接口都能用，Key 用系统钥匙串加密，只存在你的电脑上。

能干活的 Agent

读写项目文件、执行命令、操作浏览器，危险操作始终先问你。

手机远程

扫码或输入配对码，端到端加密。出门在外也能派任务、点批准。
