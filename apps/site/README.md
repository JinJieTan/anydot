# anydot.app landing page

Static files served by nginx from `/var/www/anydot.app` on the anydot.app server. Deploy by copying `index.html`, `logo-mark.svg` and `images/` there; no build step. Installers go in `/var/www/anydot.app/download/` (built locally, not in git); bump the file names in `index.html` on each release.
